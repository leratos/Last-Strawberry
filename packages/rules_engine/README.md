# Rules Engine (Greenfield)

Deterministischer Regelkern fuer die Greenfield-Webversion.

Rolle:
- verarbeitet strukturierte `TurnIntentAction`-Eintraege
- berechnet `StateDelta` + `TurnResolution`
- ist die autoritative Quelle fuer Spielzustand (nicht der Narrationstext)

Hinweis:
- Dieses Paket ist initial ein MVP-Skeleton (SRD-light vorbereitet).
