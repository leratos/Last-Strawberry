# Greenfield Web Client (React + TypeScript + Vite)

Ziel:
- Reines Spiel-Frontend (kein Marketing/SEO-Fokus)
- Hauptdomain ist `last-strawberry.com`
- Spiel laeuft spaeter auf separater Subdomain (z. B. `play.last-strawberry.com`)

## Geplanter Stack
- React
- TypeScript
- Vite
- TanStack Query (spaeter)
- Zustand (spaeter)
- React Hook Form + Zod (spaeter)

## Status
Dies ist ein Start-Skeleton mit Struktur und Grundlayout fuer den Greenfield-Track.
